This project is a CLI-based Library Management System developed using Java . The objective of the system is to manage books and users efficiently using object-oriented programming concepts. The project consists of multiple classes including Book, User, and Library. The Book class stores details such as book ID, title, author, and availability status. The User class maintains user information like user ID and name. The Library class manages collections of books and users, and implements core functionalities such as adding books, registering users, issuing books, and returning books. The system demonstrates the use of classes, objects, ArrayList, and basic CRUD operations in Java.
